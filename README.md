## Overview

# Level 1

## Task 1 - String Reversal

Create a Python function that takes a string as input and returns the reverse of that string.

**Implementation:**  
The program accepts a string from the user and displays the reversed string.

---

## Task 2 - Temperature Conversion

Create a Python program that converts temperatures between Celsius and Fahrenheit.

**Implementation:**  
The program accepts a temperature value and its unit (`C` or `F`) and displays the converted temperature.

---

## Task 3 - Email Validator

Develop a Python function that validates whether a given string is a valid email address.

**Implementation:**  
The program checks for the presence of an `@` symbol and a domain name.

---

## Task 4 - Calculator Program

Create a Python program that acts as a basic calculator.

**Supported Operations:**

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)

The program accepts two numbers and an operator and displays the result.

---

## Task 5 - Palindrome Checker

Write a Python function that checks whether a given string is a palindrome.

**Implementation:**  
The program compares the original string with its reverse and determines whether it is a palindrome.

---

# Level 2

## Task 1 - Guessing Game

Write a Python program that generates a random number between 1 and 100.

The user attempts to guess the number, and the program provides hints such as:

- Too high
- Too low
- Correct

The game continues until the correct number is guessed.

---

## Task 2 - Number Guesser

Create a number guessing game where the program generates a random number between a specified range.

The user enters a guess and the program checks whether the guess matches the generated number.

---

## Task 3 - Password Strength Checker

Create a Python program that evaluates the strength of a password.

The program checks for:

- Minimum password length
- Uppercase letters
- Lowercase letters
- Digits
- Special characters

The password is classified as strong or weak based on these conditions.

---

## Task 4 - Fibonacci Sequence

Write a Python program that generates the Fibonacci sequence up to a given number of terms.

The user enters the number of terms and the program displays the corresponding Fibonacci sequence.

---

## Task 5 - File Manipulation

Write a Python program that reads a text file and counts the occurrences of each word.

The program:

1. Reads the text file.
2. Extracts the words.
3. Counts the occurrence of each word.
4. Displays the results in alphabetical order.

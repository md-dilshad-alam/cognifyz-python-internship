## Overview

This repository contains the Python programming tasks completed during the Cognifyz Python Development Internship.

The tasks are organized according to the internship task levels.

---

## Level 1

### Task 1 - String Reversal

Reverses a string entered by the user.

### Task 2 - Temperature Conversion

Converts temperature between Celsius and Fahrenheit.

### Task 3 - Email Validator

Checks whether an entered email address follows a basic valid format.

### Task 4 - Calculator Program

Performs basic arithmetic operations including addition, subtraction, multiplication, division, and modulus.

### Task 5 - Palindrome Checker

Checks whether an entered word is a palindrome.

### Task 6 - Guessing Game

Generates a random number between 1 and 100 and allows the user to guess the number.

---

## Level 2

### Task 1 - Number Guesser

Generates a random number and checks the user's guess.

### Task 2 - Password Strength Checker

Checks password strength based on length, uppercase letters, lowercase letters, numbers, and special characters.

### Task 3 - Fibonacci Sequence

Generates a Fibonacci sequence for the number of terms entered by the user.

### Task 4 - File Manipulation

Creates a text file, writes content into it, reads the content, and displays it.
